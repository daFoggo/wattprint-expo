> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Build a clean Expo SDK 58 base app at `D:\Dev_Projects\wattprint-expo` that runs as an Android dev build on the emulator, uses Uniwind and gluestack v5, wires the core libraries, and passes `pnpm check` with zero warnings on a fresh clone.

**Architecture:** One Expo Router app scaffolded from `default@sdk-58`, with the demo removed. **Tech Stack:** Expo SDK 58, React Native 0.88 (New Architecture), Expo Router (typed routes, Native Tabs), expo-dev-client, TypeScript strict, Uniwind + Tailwind CSS v4, gluestack-ui v5, TanStack Query v5, TanStack Form, TanStack Pacer, zod, Zustand + react-native-mmkv, expo-secure-store, i18next + react-i18next + expo-localization, Reanimated 4 (SDK-pinned), ESLint (`expo lint` flat config) + Prettier, jest-expo + React Native Testing Library, Husky + lint-staged + commitlint, EAS (config only), GitHub Actions, pnpm.

## Review Focus

1. **A fresh clone fails `pnpm check` because generated type files are missing.** `expo-env.d.ts` and `.expo/types` are git-ignored, and `uniwind-types.d.ts` is generated by Metro. The test that pins this is the clean-clone `pnpm check` in Task 7, step 7.6. Ownership: the `typecheck` script runs `expo customize tsconfig.json` (Task 2), and `src/uniwind-types.d.ts` is committed (Task 3).
2. **gluestack `init` silently rewrites Metro, Babel or CSS config.** Examples: Uniwind no longer outermost, a second `global.css`, `jsxImportSource: 'nativewind'` in Babel, or a duplicated worklets plugin. When that happens, classes stop applying on device while Jest still passes. The test that pins this is the guard in `scripts/config-guard.test.ts`, extended in Task 4, step 4.1.
3. **Dynamic `process.env` access.** Destructuring or bracket access leaves values undefined in the bundle while Jest still passes. The test that pins this is the static-access case in `src/env.test.ts` (Task 6, step 6.1).
4. **Template or web leftovers ship as product code.** Examples: `web.output: "server"`, `react-native-web`, `reset-project`, demo assets. The test that pins this is `scripts/config-guard.test.ts` (Task 2, step 2.6).
5. **MMKV persistence is mocked in Jest but broken on device,** so the theme preference is lost on restart. The test that pins this is the force-stop and relaunch evidence in Task 5, step 5.12c.

## Risks / stop-and-ask points

- **`eas whoami` reports not logged in:** stop and ask the user to run `eas login`. The same applies if pnpm has no global bin directory (`pnpm setup` changes PATH; ask first) or `eas init` reports a slug mismatch.
- **TanStack Form or Pacer misbehaves on the emulator** (step 5.12b): stop and report. Don't swap libraries. Pacer was 0.x (pre-1.0) at research time; record that and flag it to the user.
- **gluestack v5 status is ambiguous:** the GitHub release text still mentions alpha. If any `@gluestack-ui/*` installs as a prerelease, stop and ask.
- **Uniwind's SDK 58 / RN 0.88 support isn't stated in its docs:** if the build fails inside Uniwind, stop and report. Don't switch to NativeWind.
- **`expo customize tsconfig.json` is interactive or not idempotent:** stop, because fresh-clone typed routes are then unresolved.
- **pnpm's isolated linker breaks native-module resolution:** switch to `nodeLinker: hoisted` in `pnpm-workspace.yaml`, then fall back to npm (as the spec allows). Record whichever you use.
- **Removing `react-dom` or `react-native-web` breaks doctor or the build, or a TanStack package needs `react-dom`:** restore it and record why.
- **Rendering gluestack or Uniwind in Jest fails beyond `transformIgnorePatterns`:** stop and report. Don't mock styling away silently.
- **Git not approved:** Husky (Task 7) and the git-based clean clone need it, so ask before Task 7.
- **Assumption:** `vi` is the second locale. Confirm it with the user in the final report.
